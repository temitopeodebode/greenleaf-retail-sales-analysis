# GreenLeaf Retail Sales Analysis
## 📊 Project Overview
This project analyzes retail sales data for GreenLeaf, a fictional retail business.
The project demonstrates how Microsoft Excel can be used to clean, organize, analyze, and visualize sales data to generate useful business insights.

## 🎯 Project Objectives
- Clean and standardize raw customer and sales data
- Identify and address data-quality issues
- Analyze sales performance
- Summarize sales using PivotTables
- Create a dashboard for easy interpretation of results
- Present key business insights from the data

## 🛠️ Tools & Skills
- Microsoft Excel
- Data Cleaning
- Data Analysis
- Excel Formulas
- PivotTables
- Data Visualization
- Dashboard Creation

## 🧹 Data Cleaning
The raw dataset contained common data-quality issues such as:
- Duplicate records
- Inconsistent capitalization
- Missing information
- Inconsistent date formats
- Extra spaces
- Formatting inconsistencies
The data was cleaned and standardized before analysis.

## 📈 Analysis
The cleaned dataset was analyzed to understand:
- Total sales
- Number of orders
- Units sold
- Average order value
- Sales performance by product
- Sales performance by location
PivotTables were used to summarize the data and support the analysis.

## 📊 Dashboard
![GreenLeaf Retail Sales Dashboard](GreenLeaf-sales-dashboard.png)
An Excel dashboard was created to provide a visual summary of the sales performance and key metrics.
